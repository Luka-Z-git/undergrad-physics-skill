# v0.8.0 Release Notes（草案）

> 状态：功能完成，尚未创建 tag 或 GitHub Release。

v0.8.0 让 `undergrad-physics-skill` 对“何时可以使用工具、何时必须手算、如何诚实报告验证”有了明确的难度分级，同时把当前覆盖边界和后续本科领域路线图写清楚。

## 面向用户的变化

- **L1 简单题**：纯手算，不自动调用外部工具；
- **L2 中等题**：环境允许时可做一次符号复核；
- **L3 复杂题**：环境允许时自动升级一次符号或数值复核；
- **L4 高置信度请求**：在 L3 基础上执行独立复核；
- 没有真实运行 Python / SymPy 时，禁止声称已经完成工具验证；
- 工具不可用时明确报告手算降级，不静默伪造结果；
- 明确当前覆盖理论力学、电磁学和基础量子力学；热学、统计物理、光学/波动与狭义相对论仍在路线图中。

## README 与首次试用

- 将项目定位明确为“AI 本科物理解答的验证与修复层”；
- 首页加入粗糙斜面误用机械能守恒的 FAIL → 定位 → 修复 → 重验案例；
- 增加 Codex 安装命令、可复制的诊断题和可观察的生效信号；
- 明确区分设计约束、演示结果与尚未完成的模型 A/B benchmark；
- Claude Code 文件布局兼容，但尚未完成与 Codex 同等规模的行为回归。

## 质量保证

- 20 个带验证的例题；
- 12 个对抗性行为用例；
- GitHub Actions 运行结构门禁、确定性数值回归与体积预算；
- 中英文 `SKILL` 与领域模块同步更新。

## 已知限制

- 本版本不承诺“使用 skill 后一定正确”；
- 尚未发布同模型、同题、同设置的 A/B benchmark；
- 尚未覆盖完整本科物理课程；
- 工具门禁依赖宿主 agent 正确执行 skill 指令，真实行为仍需用回归与用户案例持续验证。

## 下一步：v1.0

v1.0 的核心交付不是继续增加内部规则，而是公开可复现的物理解题 benchmark，报告答案正确率、关键推导正确率、未发现矛盾、无证据 PASS，以及 token / 延迟成本。
