# 错误预防 (Error Prevention)

本模块定义推导过程中必须遵守的错误预防规则、各领域常见陷阱表与交卷前检查清单。规则在推导步骤（核心工作流第 3 步）持续生效，检查清单在作答（核心工作流第 6 步）前整体执行一次。

## 0. 通用纪律

1. **不编造**：不发明定理、公式或"显然成立"的步骤。不确定的中间步骤明确标注，不得用含糊措辞掩盖。
2. **全程携带单位**：每个物理量带单位，中间结果量纲与语境一致；单位制（SI/CGS）在解析步骤显式声明，推导中不得混用。
3. **写全步骤**：每步代数变换显式写出；在关键中间结果、近似/表示切换和最终结果前执行适合的快速核验并内联记录结果。
4. **定理先验条件**：引用任何定律/定理前，先验证其适用条件成立（惯性系、无耗散、势场、定态、小角等），并在文中声明。

## 1. 代数与微积分在物理中的常见错误

| 陷阱 | 错误 | 正确 |
|---|---|---|
| 丢掉 $1/2$ | 动能写 $mv^2$ | $T=\frac{1}{2}mv^2$ |
| 平方根符号 | $\sqrt{x^2}=x$ | $\sqrt{x^2}=\|x\|$ |
| 链式法则 | $\frac{d}{dt}V(q(t))=\frac{dV}{dq}$ | $\frac{d}{dt}V(q)=\frac{dV}{dq}\dot q$ |
| 积分常数/初值 | 解微分方程后不写积分常数 | 由初始条件确定常数；漏定初值导致解族不唯一 |
| 量纲混用 | SI 与 CGS 混用 | 解析步骤声明单位制，全程一致 |

## 2. 力学

### 2.1 建模阶段

- **坐标系与惯性系**：牛顿第二定律仅在惯性系成立；非惯性系必须显式加入惯性力（牵连、科里奥利、离心），并声明参考系。
- **约束分类**：使用拉格朗日力学前确认约束完整（holonomic）且理想；非完整约束或摩擦系统需改用广义力或拉格朗日乘子，并说明理由。
- **广义坐标**：自由度 = 独立坐标数；少选或多选坐标会导致方程数错误。
- **势能零点**：势能加常数不影响运动方程；选择后全文一致。

### 2.2 拉格朗日力学

- **$L = T - V$ 的符号**：写反 $T+V$ 是最常见错误；检查 $\partial L/\partial \dot q$ 对动能项给出 $m\dot q$ 而非 $-m\dot q$。
- **E-L 方程结构**：$\frac{d}{dt}\frac{\partial L}{\partial \dot q_i} - \frac{\partial L}{\partial q_i} = 0$；$\partial L/\partial q_i$ 的符号（来自 $V$ 的负号）是高频出错点。
- **循环坐标与守恒**：$L$ 不含 $q_i$ → 广义动量 $p_i = \partial L/\partial \dot q_i$ 守恒；$L$ 不显含时间 → 广义能量（Jacobi 积分）$h = \sum p_i\dot q_i - L$ 守恒，且仅当约束定常时 $h$ 才等于机械能 $T+V$。判据是 $L$ 的显式依赖，不是"看起来像"。
- **能量与哈密顿量**：$H = \sum p_i \dot q_i - L$；仅当约束定常（不显含时间）时 $H = E$，且 $E$ 才等于 $T+V$。

### 2.3 小振动与简正模式

- **平衡点**：先解 $\partial V/\partial q_i = 0$ 找平衡位形；$\omega^2 < 0$ 表示不稳定平衡（指数增长），不是振动。
- **小角/小位移近似**：$\sin\theta \approx \theta$ 仅在 $\theta \ll 1$（弧度）成立；近似后必须声明适用范围，大振幅需高阶修正。
- **简正坐标**：频率由 $\det(K - \omega^2 M) = 0$ 给出；$K$ 为刚度矩阵、$M$ 为质量矩阵，写错矩阵元顺序是常见错误。

### 2.4 陷阱表

| 陷阱 | 错误 | 正确 |
|---|---|---|
| 惯性系误用 | 在加速车厢中用牛顿第二定律不加入惯性力 | 声明非惯性系并加惯性力项 |
| E-L 符号 | $L = T + V$ 或 $\frac{\partial L}{\partial q}$ 符号错 | $L=T-V$，逐项核对符号 |
| 能量守恒误用 | 有耗散（摩擦/阻尼）仍用 $E=\text{const}$ | 先验证无耗散或显式计入耗散 |
| 小角越界 | 大振幅仍用 $\sin\theta\approx\theta$ | 声明 $\theta\ll1$，否则用椭圆积分 |
| $\omega$ 混淆 | 把角频率 $\omega$ 当角速度 $\dot\theta$ | $\omega=\sqrt{k/m}$ 是常数；$\dot\theta$ 是变量 |

## 3. 电磁学与量子力学（跨域检查）

本表仅列跨域共性检查；电磁学与量子细则分别见 `electromagnetism.md`、`quantum_basics.md`。

- **电磁学**：矢量算符（梯度/散度/旋度）作用于标量/矢量的规则；积分形式与微分形式的适用边界；边界条件在界面处的连续性。
- **量子力学**：算符顺序（不对易时不可交换）；波函数归一化 $\int|\psi|^2\,dx = 1$；厄米算符本征值为实数。
