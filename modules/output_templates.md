# 输出模板 (Output Templates)

本模块定义输出规格。核心原则：**结构清晰、信息密度高、格式与交付目标一致**。默认输出是 Markdown + LaTeX 公式；只有在用户要求可编译文档时才进入 LaTeX 文档模式。

## 模板选择

| 用户请求 | 模板 |
|---|---|
| 解一道题 / 推导 / 求解 | A 标准解答（默认） |
| "只要答案" / "直接给结果" | B 仅答案 |
| "帮我看看这步对不对" / 给出已有解答求审 | C 解答检查 |
| 概念/原理问答（无需长推导） | D 概念问答 |
| "诊断" / "看看我写的" / "我哪里错了" | E 学生诊断 |

## 模板 A：标准解答

按顺序输出以下 6 节，标题逐字使用下方标题，每节必须独立成节。禁止把建模与推导合并、禁止把验算写成混合散文、禁止把易错点并入答案。输出前必须通过下方结构门禁。

固定标题（逐字使用）：`题意与图景`、`建模`、`推导`、`验算`、`答案`、`易错点`。

### 1. 题意与图景

- 一句话重述物理系统：对象、自由度、约束、坐标系、单位制、初始/边界条件。禁止复述题目原文。
- 一行列出：已知量（符号+数值+单位）→ 待求量。

### 2. 建模

- 写出选用的方程体系（牛顿/拉格朗日/哈密顿/麦克斯韦/薛定谔）及选择理由（一个分句，如"约束完整且非保守力可并入广义力，故用拉格朗日"）。
- 写出 $L$、$H$ 或 EOM 的显式形式。
- 声明每个被引用定律的适用条件（惯性系、无耗散、势场、定态…）。

### 3. 推导

- 分步推导，每步标注依据（"由 E-L 方程"、"代入约束"）。
- 先符号后数值：全程先做符号推导，最后才代入具体数值。
- 在关键中间结果、近似/表示切换和最终结果前，执行最适合的快速核验并内联记录。
- 矩阵/特征值/矩阵幂/递推子问题调用 `math-skill` 时，注明借用了哪些结果（如"矩阵部分由 math-skill 验证"）。

### 4. 验算

- 逐条列出：**方法名 + 实际执行的内容 + PASS/FAIL/N/A（原因）**。
- 每条 PASS 必须含可复核的具体检查（表达式/代入值/极限）；纯结论式 PASS 视为未完成并回溯。
- 选择最小充分验算集：通常包含 F 量纲和 B 回代，并至少加入一个与之独立的 L 极限/特例、C 守恒量、D 定义域、E 数值抽样、I 独立方法或 J 一致性检查。仅保留实际适用的项。
- 领域模块要求的 J 一致性（小振动/简正模式、算符与对易关系、矩阵/特征值/递推）必须加入，不可用其他检查替代。
- 每项独立一行并编号；编号反映实际选择，不要求连续。N/A 必须写明物理原因。失败项修复后，在该项标注"修复后 PASS"。

### 5. 答案

- 最终结果必须用 Markdown 加粗：`**...**` 包裹完整结论（中文结论、公式、单位）。公式内可另用 `\boxed{}` 强调，但 `\boxed{}` 不视为显式加粗；答案节缺失 `**...**` 按 FAIL 处理。
- 附一行验算摘要，列出实际检查，例如：`验算：①F、②B、③L，FAIL 0 项`；不适用项写 `N/A（原因）`。

### 6. 易错点

- 只写本题真实存在的风险 1–3 条；无则不写。

## 模板 A 结构门禁（作答前逐项核对）

输出最终答案前，逐项检查；任一未满足则重构输出，不得直接作答：

- [ ] 六节标题完整且顺序正确：题意与图景、建模、推导、验算、答案、易错点
- [ ] 每节独立成节；建模与推导未合并，易错点未并入答案
- [ ] 验算节列出最小充分验算集：F、B（适用时）和至少一项独立检查；本域必做 J 已加入
- [ ] 答案节含 `**...**` 显式加粗；`\boxed{}` 不作为替代

## 模板 B：仅答案

- 直接给结果（加粗、含单位）。
- 必须附一行验算摘要——不允许零验证的裸答案。

## 模板 C：解答检查

- 逐条指出：哪一步正确（引用步骤）、哪一步错误（引用步骤 + 具体原因）。
- 对每个错误给出修正后的步骤。
- 结尾给一行结论：`结论：解答正确/解答含 N 处错误，已修正`。

## 模板 D：概念问答

- 直接回答 + 一个最小示例说明；不做无关展开。

## 模板 E：学生诊断

用于检查学生作答，不展开完整解答。固定字段与顺序：

1. **完整性结论**：`完整` 或 `不完整（缺：方法/方程/推导/答案）`
2. **核验结果**：逐条 `①F ... PASS/FAIL/N/A（原因）`、`②L ...`、`③B ...`、`④C ...`
3. **问题定位**：`第 N 步 / 表达式 / 错因`
4. **概念误区**：`对应的物理概念或适用条件`
5. **修正建议**：`正确写法 + 为什么`
6. **确认题**：`一道需要学生回答的短问题`

规则：

- 不完整时直接指出缺项和下一步具体写什么；不做提示分级。
- 不自动输出模板 A 完整答案；学生明确要完整答案时再切回主流程。
- 每条核验必须含 `PASS`/`FAIL`；无法核验时写 `N/A（原因）`。
- 每条核验必须含可复核的具体检查（表达式/代入值/极限）；纯结论式 PASS/FAIL 视为未完成。

## 格式硬规则

1. **公式**：独立公式一律 `$$ ... $$`；行内公式用 `$...$` 仅限短符号（$x$、$\theta$）。整行公式禁止用单 `$`。
2. **LaTeX 兼容**：只用标准 LaTeX 宏包可用语法（`\frac`、`\sqrt`、`\int`、`\sum`、`\mathrm`、`\begin{cases}`）；不输出 emoji、对勾/叉号等 Unicode 符号；验证结果用 `PASS`/`FAIL` 纯文本。
3. **单位**：全程携带单位；数值题给数值结果必须带单位。
4. **语言**：中文叙述；物理术语保留标准形式（Lagrangian、Hamiltonian、Schrödinger 等可保留英文或中英并注）。
5. **可复制性**：默认 Markdown 输出可直接阅读和复用公式；用户要求编译文档时，切换到下方 LaTeX 文档模式。不要把 Markdown 标记当作 LaTeX。
6. **长度**：推导每步可独立验证，不跳步；但删除所有与解题无关的句子。
7. **结构门禁**：模板 A 必须满足六节固定标题、独立成节、最小充分验算集和答案 `**...**` 加粗四项；任一不满足则先重构输出。

## 反例（禁止出现的输出）

- "好的！让我们一步一步来分析吧～"（口号式开场）
- "因此，答案是 2，非常简单！"（无依据结论）
- "我相信这个结果是正确的"（用信念代替验证）
- 把 Markdown 标记当作可直接编译的 LaTeX 文档

## LaTeX 文档模式（仅用户要求编译文档时）

将 Markdown 标题改为 `\section*{...}`，将 `**结论**` 改为 `\textbf{结论}`；验证编号使用普通 `1.`、`2.`，避免依赖 Unicode 字符。交付完整文档时使用以下最小前导：

```latex
\documentclass[UTF8]{ctexart}
\usepackage{amsmath,amssymb}
\begin{document}
% 将六节内容写为 \section*{题意与图景} 等
\end{document}
```

此模式不使用 Markdown 表格、`**...**` 或圈号数字；数值、公式和验算依据与 Markdown 模式相同。

## 难度分级与输出粒度（核心工作流第 1 步执行）

在解析（Parse）阶段完成后、进入建模前，评估题目复杂度并按以下规则自适应输出粒度。任何难度都使用最小充分验算集，不为凑检查而添加不适用项目。

| 复杂度 | 判据 | 输出粒度 |
|---|---|---|
| **简单** | 推导 ≤ 3 步；单自由度；标准题型（恒力运动、单摆小角、RC 放电、无限深势阱） | 模板 A 六节保持独立但每节可简短；易错点无则不写 |
| **中等** | 推导 4–10 步；1–2 自由度；含选择/判断（方法选型、坐标系选取） | 标准模板 A 六节完整输出 |
| **复杂** | 推导 > 10 步；多自由度耦合（双摆、耦合振子）；或用户要求高置信度 | 标准模板 A + 可选复核（`review_engine.md` P1–P5）；复核结论附在答案后 |

**纪律**：
- 复杂度评估在解析步骤末尾用一句话声明，如"本题评估为：中等（双自由度耦合，推导约 6 步）"。
- 简单题的紧凑写法不省略已选择检查的具体依据，也不要求加入不适用检查。
- 用户明确要求"详细解答"/"完整步骤"时，无视自动分级，一律按复杂题标准输出。
