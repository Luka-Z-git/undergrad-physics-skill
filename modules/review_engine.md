# 独立复核引擎 (Independent Review Engine)

本模块是**可选**后置复核协议，不参与主流程默认执行。用途：在标准解答完成后对整份推导做独立审查，快速定位可疑步骤并决定是否整体重推。适用于用户要求高置信度、题目复杂、或标准验证曾 FAIL 后重验通过的情形。

零外部依赖：复核由推理本身执行，不调用脚本；可选的符号复核见 `computation.md`。

## 1. 何时使用

- 用户明确要求"复核/审查/再检查"。
- 题目复杂，或标准验证曾 FAIL（即使修复后 PASS）。
- 用户提供已有解答要求审查（模板 C 可先用本协议定位错误）。

默认输出：P1–P5 逐项摘要 + 一行结论；不做无关展开。

## 2. 病理过滤器 (Pathology Filter)

按顺序检查整份推导，任一 FAIL 即记录病态：

| 代号 | 检查 | 病态判定 |
|---|---|---|
| P1 | 量纲 | 任一中间或最终表达式的量纲与目标物理量不符 |
| P2 | 守恒 | 无耗散或对称性成立时，能量/动量/角动量不守恒或守恒表达式随时间漂移 |
| P3 | 极限 | 参数趋于已知极限（$\omega\to0$、$\hbar\to0$、$\theta\to0$、$m\to\infty$）时结果不退化为已知形式 |
| P4 | 因果/方向 | 结果违反时间顺序、参考系方向约定，或力与相对运动方向的关系 |
| P5 | 定义域 | 结果在参数边界发散、频率平方为负、能量为负而适用条件未声明 |

每条 FAIL 必须记录：**发现步骤 + 具体差异 + 首个可疑中间结果**。不允许只写"结果有错"。

## 3. 白纸重推 (Blank-Paper Restart)

默认不执行白纸重推；仅当用户明确要求或病理过滤器发现 FAIL 时才执行。执行时：

1. 丢弃从首个可疑中间结果往后的全部工作，禁止局部改符号打补丁。
2. 从最后一个通过检查的完整中间结果（没有则回到建模）重新推导。
3. 重推换一条可独立核验的路径，或至少换一种推导组织方式。
4. 重推完成后重新执行所选的最小充分验算集与全部 P1–P5。

若重推结果与初稿一致且所有检查通过，记录"复核未发现病理"，不强行制造分歧。

## 4. 复核结论格式

通过时：

```
复核：P1 量纲 PASS · P2 守恒 PASS · P3 极限 PASS · P4 因果 PASS · P5 定义域 PASS，FAIL 0 项
```

发现病理并重推后：

```
复核：P2 守恒 FAIL（第 N 步能量表达式随时间变化），已白纸重推，重推后 FAIL 0 项
```

复核结论附在最终答案之后一行。

## 5. 边界

- 复核不替代标准验证引擎的 PASS/FAIL 记录；两份记录都保留。
- 复核与主流程结论冲突时，按 `verification_engine.md` 回溯修正协议处理，不得单方面采信任一方。
- 本模块仅借鉴病理过滤与白纸重推的方法思路，条文为独立编写，未复制任何外部原文。
