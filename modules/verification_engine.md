# 验证引擎 (Verification Engine)

本模块定义 8 种验证方法（F/D/B/C/L/E/I/J），题型选择表，回溯修正协议，以及验算摘要格式。任何解答在给出最终答案前必须通过本引擎。

## 方法总览

| 代号 | 名称 | 做什么 | 判定 |
|---|---|---|---|
| F | 量纲检查 | 推导全程携带单位；最终表达式的量纲必须与目标物理量一致 | 量纲不符 → FAIL |
| D | 定义域/参数域 | 解的物理域：参数范围、分母非零、根号实性、频率平方非负、能量实性 | 越界/未声明 → FAIL |
| B | 回代 | 把解代回原始方程（EOM、E-L 方程、$H\psi=E\psi$、电路方程）验证恒等 | 代回不恒等 → FAIL |
| C | 守恒量 | 能量/动量/角动量守恒（系统无耗散、对称性成立时）；验证 $T+V=\text{const}$ | 数值演化不守恒 → FAIL |
| L | 极限/特例 | 令参数趋于已知极限（$\omega\to0$、$\hbar\to0$、$m\to\infty$、$\theta\to0$）应还原已知结果 | 极限不自洽 → FAIL |
| E | 数值抽样 | 取具体数值代入中间与最终表达式，比较等式两边并核对数量级 | 数值不等或数量级离谱 → FAIL |
| I | 独立方法 | 用另一体系重解（牛顿 vs 拉格朗日；能量法 vs 力法；另一种规范） | 结果不一致 → FAIL |
| J | 一致性 | 矩阵/线代：迹、行列式、$A\mathbf{v}=\lambda\mathbf{v}$ 回代、$PDP^{-1}=A$ 重建；量子：归一化 $\int|\psi|^2=1$、$\sum|c_n|^2=1$、对易关系 | 不满足 → FAIL |

## PASS 判据

每条 PASS 必须附可复核的具体检查：量纲代入、极限表达式、回代恒等、守恒量数值，或数值抽样；纯结论式 PASS（如仅写"量纲正确"）视为未完成，按 FAIL 处理并进入回溯修正协议。禁止伪造 PASS。工具调用按 L1–L4 门禁执行：简单题禁止；中等题允许一次符号复核；复杂题环境可用时自动升级一次；工具不可用时手算并声明。未实际执行工具时禁止声称已用外部工具验证；用户明确要求符号复核时无论难度最多执行一次并标注来源。

## 方法细节

### F 量纲检查（通常必做）

1. 解析步骤声明单位制（SI/CGS）与基本量纲 $[M],[L],[T],[Q]$。
2. **最终表达式和每步有物理意义的中间结果必须携带单位**；纯数学运算阶段（矩阵求逆/特征值计算/积分技巧/代数化简）允许无量纲中间步骤，但在重新赋予物理意义时必须立即恢复单位并核对量纲。
3. 最终表达式量纲 = 目标物理量量纲。示例：简谐角频率 $\omega=\sqrt{k/m}$，$[\omega]=[k/m]^{1/2}=[\mathrm{N/(kg\cdot m)}]^{1/2}=\mathrm{s^{-1}}$。
4. 常见量纲记忆：$[E]=ML^2T^{-2}$，$[\hbar]=ML^2T^{-1}$，$[\mathrm{electric\ field}]=MLT^{-3}I^{-1}$。

### D 定义域/参数域检查

- 分母、对数、根号下的物理量非负/非零条件是否已声明。
- 频率 $\omega^2>0$ 才代表振荡；$\omega^2<0$ 表示指数增长（不稳定平衡附近），须指出。
- 解的适用区间（如小角近似 $\theta \ll 1$、非相对论 $v\ll c$、弱场）必须与推导假设一致。

### B 回代检查

把最终解 $x(t)$、$\theta(t)$、$\psi(x)$ 代回原方程，逐项化简，两边必须恒等。例：解得 $\theta(t)$ 后代入 $\ddot\theta+\omega^2\theta=0$ 验证。

### C 守恒量检查

- 拉格朗日量不含某坐标 → 对应广义动量守恒（Noether）；哈密顿量不含时 → 能量守恒。
- 验证方法：取两组不同时刻的状态，计算 $E=T+V$ 或 $p$，必须相等。

### L 极限/特例检查

- 令参数取已知极限，结果必须退化到熟悉表达式。例：旋转环上的珠子 $\omega\to0$ 时应退化为单摆 $\Omega^2=g/R$；量子结果 $\hbar\to0$ 时趋于经典。

### E 数值抽样检查

- 取简单数值（如 $m=1,\ k=1,\ g=9.8$），分别代入等式两边，逐项算到小数点后若干位。
- 对三角函数/指数代入特殊角或特殊值（$\theta=0,\pi/2$）验证恒等式。
- 核对结果数量级符合物理常识：宏观速度远小于 $c$、力在常见量级、能量非负等；数量级离谱即 FAIL。

### I 独立方法检查

- 用不同方法重解同一问题并比较：牛顿第二定律 vs 拉格朗日；能量守恒 vs 直接积分；直角坐标 vs 极坐标。
- 适用于难题、验证失败后、或用户要求高置信度时。

### J 一致性检查

- 矩阵问题：$\mathrm{tr}(A)=\sum\lambda$，$\det(A)=\prod\lambda$，特征向量回代 $A\mathbf{v}=\lambda\mathbf{v}$，重建 $PDP^{-1}=A$。
- 量子问题：波函数归一化、概率和 $\sum|c_n|^2=1$、$[\hat x,\hat p]=i\hbar$ 等对易关系。
- 递推/矩阵幂问题：小 $n$ 手算核对 $A^2,A^3$ 再推广。

## 题型 → 验证组合选择表

模板 A（标准解答）使用最小充分验算集：通常包含 F 量纲和 B 回代，再加入至少一个独立的 L、C、D、E、I 或 J 检查；每个 N/A 都要说明物理原因。领域模块标为必做的 J 一致性必须加入，不能以其他检查替代。下表给出各题型的优先组合与领域强调。

| 题型 | 推荐最小充分组合 | 领域强调 |
|---|---|---|
| 牛顿力学/受力分析 | F + B + D 或 L | 定义域（摩擦/静摩擦条件）；B 回代用于运动方程解 |
| 拉格朗日/哈密顿推导 | F + B + I 或 C | 独立方法（牛顿重解）与守恒量是强校验 |
| 小振动/简正模式 | F + B + J | J 本域必做：特征值回代、M-正交 |
| 守恒量问题 | F + B + C 或 I | 独立方法重解核对守恒量 |
| 静电场/电势 | F + B + D 或 L | 边界条件回代与叠加性 |
| 电路 RC/RL/RLC | F + B + L 或 C | 时间常数量纲与 $t\to0,\infty$ 行为 |
| 麦克斯韦/矢量分析 | F + B + J 或 D | 恒等式两侧展开比较 |
| 定态薛定谔/一维势 | F + B + J | J 归一化；B 回代已必查 |
| 算符/对易关系 | F + B + J | J 本域必做：直接展开验证 |
| 矩阵/特征值/递推 | F + B + J | J 本域必做：迹/行列式/回代/重建 |

## 回溯修正协议

验证 FAIL 时：

1. **记录失败**：哪个方法、哪一步、具体差异。
2. **回溯**：定位最后一个通过的中间结果；其后的工作全部视为可疑。
3. **诊断**：错误类别——代数错误、符号错误、量纲错误、定理适用条件不满足、丢解、边界条件遗漏。
4. **修正**：从回溯点重推，向前传播。
5. **重验**：用原方法 + 至少一个额外方法（优先 I 独立方法）。
6. **两次修正仍失败** → 换独立求解路线；仍失败 → 明确声明无法给出已验证答案，并报告已验证的中间结果。禁止伪造 PASS。

### 成本止损机制（v0.5 新增）

为避免复杂题目（双摆、耦合振子等）回溯导致 token 消耗失控，引入以下止损规则：

#### 6a. 轻量回代选项

当 FAIL 仅出现在推导末尾的 1–2 步（如最终表达式符号错误、数值代入算错），且前面所有中间结果均已通过独立核验时，允许**局部修正**而非全量回溯：

- 仅对 FAIL 的步骤及其直接依赖的前驱做重做；
- 保留已通过的全部前置中间结果，不标记为"可疑"；
- 局部修正后仍须对最终答案重新执行所选的最小充分验算集。

**触发条件需同时满足**：(a) FAIL 出现在推导 80% 之后的步骤；(b) 前置中间结果均已通过至少两种独立验证。

#### 6b. 成本止损点

当重推路径的操作步数超过初稿的 **150%** 时，停止同路径修正，直接切换到**独立方法 I**（牛顿 vs 拉格朗日、能量法 vs 力法、矩阵法 vs 代数法）。不再尝试第三次同路径修正。

#### 6c. 复杂题标记

以下题型自动标记为"复杂"，在回溯协议第 6 步时**跳过第二次同路径修正**，直接进入独立方法切换：
- 双摆及更高自由度耦合系统
- 含完整约束消元 + 广义坐标选择的拉格朗日问题
- 需要分离变量 + 特殊函数的量子问题（氢原子径向方程）
- 矢量积分 + 对称性分析的电磁学问题（非高对称）

**复杂题标记应在解析阶段末尾与难度分级一同声明。**

#### 止损记录格式

触发轻量回代或成本止损时，在验算摘要中注明：

```
验算：①F、②B、③I，FAIL 0 项（⑥ 成本止损：重推路径超 150%，切换至 I 独立方法后 PASS）
```

或：

```
验算：①F、②B、③L，FAIL 0 项（⑥a 轻量回代：仅修正第 N 步符号错误）
```

## 验算摘要格式

最终答案末尾必须附一行摘要，格式：

```
验算：①F、②B、③L，FAIL 0 项
```

可带明细，例如：`验算：①F 量纲 ②B 回代 ③L 极限(ω→0 退化为单摆)，FAIL 0 项`。若某项 FAIL 后修复，写 `修复后 PASS`；不适用项写 `N/A（原因）`。
