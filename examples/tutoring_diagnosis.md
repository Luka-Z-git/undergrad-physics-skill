# 例题：学生诊断模式（模板 E 示范）

> 本示例展示可选学生诊断模式：直接指出缺项与错误，不展开模板 A 完整解答。

## 场景 A：不完整进度

学生作答："对单摆取广义坐标 $\theta$，写 $L = T - V$，后面不会了。"

### 诊断输出

1. **完整性结论**：不完整（缺：推导、答案）
2. **核验结果**：尚未进入数值核验（推导与答案缺失）
3. **问题定位**：已写出 $L = T - V$，但未代入 E-L 方程
4. **概念误区**：写出 $L$ 不等于完成建模，还需由

$$
\frac{d}{dt}\frac{\partial L}{\partial\dot\theta} - \frac{\partial L}{\partial\theta} = 0
$$

生成运动方程
5. **修正建议**：下一步具体写出 $T = \frac12 ml^2\dot\theta^2$、$V = mgl(1-\cos\theta)$，再计算 $\partial L/\partial\dot\theta$ 与 $\partial L/\partial\theta$
6. **确认题**：为什么这里用拉格朗日法而不是牛顿法？

## 场景 B：完整但错误

学生作答："RC 放电，$V(t) = V_0 e^{+t/\tau}$，$\tau = RC$。"

### 诊断输出

1. **完整性结论**：完整
2. **核验结果**：①F 量纲 PASS；②L 极限/特例 FAIL（$t\to\infty$ 时 $V$ 发散而非衰减到 0）；③B 回代 FAIL（$V_0e^{+t/\tau}$ 不满足 $\dot V + V/\tau = 0$）；④C 守恒量 FAIL（电容能量单调增加，与电阻耗散矛盾）
3. **问题定位**：指数符号，$V(t) = V_0e^{+t/\tau}$ 应为 $V(t) = V_0e^{-t/\tau}$
4. **概念误区**：电流方向约定 $I = -C\dot V$ 与 KVL 方向不一致时，符号写反会得到增长解
5. **修正建议**：沿 $I$ 方向列 KVL 得 $V - IR = 0$，由 $I = -C\dot V$ 得 $\dot V + V/(RC) = 0$，解为 $V_0e^{-t/\tau}$
6. **确认题**：如果电流方向取反，KVL 方程和指数符号会怎么变？

## 场景 C：完整且正确（概念确认）

学生作答："无限深势阱我算到 $\psi_n = \sqrt{2/L}\sin(n\pi x/L)$、$E_n = n^2\pi^2\hbar^2/(2mL^2)$，对吗？"

### 诊断输出

1. **完整性结论**：完整
2. **核验结果**：①F 量纲 PASS（$E_n$ 为能量、$\psi$ 满足 $\int|\psi|^2dx$ 无量纲）；②L 极限/特例 PASS（$L\to\infty$ 能级间距趋于零）；③B 回代 PASS（$\psi_n''=-(n\pi/L)^2\psi_n$ 代入定态方程恒等）；④C 守恒量 PASS（定态概率密度不显含时间）；J 归一化与正交 PASS
3. **问题定位**：无错误
4. **概念误区**：无
5. **修正建议**：无需修正
6. **确认题**：为什么 $n=0$ 不是允许的量子数？（提示：代入波函数看看会发生什么）

## 场景 D：边界条件错误

学生作答："一维无限深势阱 $0<x<L$，我得到 $\psi = A\sin(kx) + B\cos(kx)$，由 $\psi'(0)=0$ 和 $\psi'(L)=0$ 得..."

### 诊断输出

1. **完整性结论**：不完整（推导中途使用了错误的边界条件）
2. **核验结果**：①F 量纲 N/A（中间步骤）；②L N/A；③B N/A；④C N/A
3. **问题定位**：第 2 步——无限深势阱的边界条件是**波函数为零**（$\psi(0)=\psi(L)=0$），而非导数为零。导数连续只适用于有限势垒。
4. **概念误区**：混淆了"波函数连续"与"导数连续"的适用条件——势能有限时 $\psi'$ 连续；势能无穷大处 $\psi=0$ 但 $\psi'$ 不要求连续
5. **修正建议**：由 $\psi(0)=0$ 得 $B=0$；由 $\psi(L)=0$ 得 $\sin(kL)=0$ → $k_n=n\pi/L$（$n=1,2,\ldots$）
6. **确认题**：对于**有限**方势阱（深度 $V_0$），边界条件应该用 $\psi$ 连续还是 $\psi'$ 连续？两者都要？

## 确认题质量校准参考

以下对照表供诊断模式出题时参考。良好确认题应**触发主动推理**而非机械复述。

| 场景 | 良好确认题 | 不良确认题 | 差异 |
|---|---|---|---|
| RC 指数符号错 | "如果我把电流方向定义反过来，$I = +C\dot V$，那么解出来的 $V(t)$ 应该是什么形式？还是指数衰减吗？" | "你理解了吗？" | 良好题要求反向推理；不良题无法检验理解 |
| $L=T+V$ 符号错 | "写出 $\partial L/\partial \dot\theta$，如果 $L=T+V$ 你会得到什么？这和牛顿第二定律的力方向矛盾吗？" | "记住 L=T-V 就行了" | 良好题让学生自己发现矛盾；不良题是死记硬背 |
| 边界条件错 | "对于**有限**方势阱，边界条件应该用 $\psi$ 连续还是 $\psi'$ 连续？两者都要？为什么和无限深不同？" | "记住无限深是 ψ=0" | 良好题建立对比加深理解；不良题只是替换记忆 |
| 无限深势阱正确作答 | "为什么 $n=0$ 不是允许的量子数？代入波函数看看会发生什么。" | "答对了，下一个吧" | 良好题探查边界理解；不良题浪费了确认机会 |
| 量纲/单位遗漏 | "这道题如果我用 CGS 单位制做，最终答案的数值会变吗？量纲呢？" | "下次记得带单位" | 良好题深化单位制理解；不良题只是提醒 |

**出题原则**：
- 确认题必须能用 1–3 句话回答，但回答需要**经过推理**，不能从原题答案中直接抄。
- 优先让学生**换个视角**看同一个物理（反事实、极限、对比、推广）。
- 避免是非题（"对吗？"）和纯记忆题（"记住 X=Y"）。
