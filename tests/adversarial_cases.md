# 对抗性行为测试

这些用例检验 skill 是否实际执行了验算，而不是只满足输出结构。每次修改核心流程或验证引擎后，逐例运行并人工记录实际输出与结论。

## TC-ADV-001：量纲错误不能通过

**输入：** "物块受恒力 F，从静止出发，位移是 $x=Ft/m$，对吗？"

**必须观察到：** F 检查为 FAIL，指出结果量纲为速度而非长度；不得给出 PASS 或仅修正最终答案而不说明错误依据。

## TC-ADV-002：边界条件不能漏用

**输入：** "无限深势阱 $0<x<L$ 的基态是 $\psi=A\cos(\pi x/L)$。"

**必须观察到：** B 检查指出 $\psi(0)\ne0$，并要求/给出满足两端边界条件的形式；J 检查处理归一化。

## TC-ADV-003：耗散系统不能伪称能量守恒

**输入：** "带动摩擦的斜面下滑，直接用 $\frac12mv^2=mgs\sin\alpha$。"

**必须观察到：** C 检查明确 FAIL 或 N/A（耗散），改用功能原理或牛顿定律；不把 C 写为无依据 PASS。

## TC-ADV-004：不适用项目不得用于凑数

**输入：** "给定静电势 $V(x,y)$，求电场。"

**必须观察到：** 选择 F + B + D/L 等适用组合；不要求无时间演化问题执行守恒量检查。

## TC-ADV-005：LaTeX 交付模式

**输入：** "用可直接在 Overleaf 编译的完整文档解 RC 放电。"

**必须观察到：** 输出含 `ctexart`、`amsmath`、`\begin{document}`，使用 `\section*`、`\textbf` 与普通数字编号；不混入 Markdown 标题、`**...**` 或圈号数字。

## TC-ADV-006：示例按索引按需读取

**输入：** "求两耦合振子的简正频率，给高置信度推导。"

**必须观察到：** 只读取 `examples/INDEX.md` 所指向的 `coupled_oscillators.md`（而不是扫描所有示例），并执行 J 特征值回代与 M-正交检查。

## TC-ADV-007：简单题走模板 B

**输入：** "RC 放电，直接给 V(t)、I(t)、tau 就行，不要推导。"

**必须观察到：** 进入模板 B，只给加粗结果加最小验算摘要；不展开六节完整答案。

## TC-ADV-008：概念题走模板 D

**输入：** "什么是厄米算符？"

**必须观察到：** 进入模板 D，直接回答加一个最小示例；不强行套用模板 A 六节。

## TC-ADV-009：诊断不泄漏完整答案

**输入：** "看看我写的这步对不对：E-L 方程我写反了。"

**必须观察到：** 进入模板 E，只指出错误与修正方向；不自动输出完整六节解答。

## TC-ADV-010：LaTeX 文档模式不混 Markdown

**输入：** "用 Overleaf 文档解无限深势阱。"

**必须观察到：** 输出 `\section*{...}`、`\textbf{...}` 与普通数字编号；不含 `**...**`、`##` 或圈号数字。
